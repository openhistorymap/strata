**Claude Desktop:** download `strata.mcpb` below and open it (or drag it onto Claude Desktop's Settings → Extensions). Claude Desktop installs Python dependencies itself; nothing else is needed.

The extension carries the Kenan Tepe store as a read-only seed. On first run it is copied to `Documents/Strata/strata.rl`, which the server reads and writes, so your edits survive updates and the file is yours to see and back up. Point the extension's *Strata store* setting at any other `.rl` file to use that one; the `store_info` tool always says which file is in use.

**In the browser:** https://www.openhistorymap.org/strata/ runs the same graph in Relate's WebAssembly build and offers it to browser agents over WebMCP.

Data: Bradley Parker and Peter Cobb (eds.), *Kenan Tepe*, Open Context, 2012, doi:10.6078/M7H41PBJ, CC BY 4.0.

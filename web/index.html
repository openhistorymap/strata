    On this site

      From a URL

      The server must allow cross-origin requests (CORS); GitHub raw files and Zenodo do. The link to this page keeps the URL, so you can share it.

      From your computer

      Drop a .strata.json file here or click to choose one. It is read in this tab. Nothing is uploaded.

      Make one from any excavation Strata can import:
      uv run strata --db my-dig.rl import-matrix my.hmcx --site my-dig
      uv run strata --db my-dig.rl export-web --site my-dig --bundle my-dig.strata.json
      Drop to open this file in Relate, in this tab
